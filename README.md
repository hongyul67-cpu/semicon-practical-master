# 반도체설비보전 실기 마스터

반도체설비보전기능사(구 반도체장비유지보수기능사) **실기** 대비 학습도구입니다.
단일 HTML — 파일 하나만 열면 됩니다.

## 담긴 것

- **배우기 12쪽** — 조립작업 6쪽(재료·피팅 체결·절단/벤딩·도면 읽기·누설검사) + 제어작업 6쪽(하드웨어 규칙·공압회로·동작 용어·변위단계선도·채점 포인트)
- **조립 도면 12장** — Q-Net 공개도면 전체. 정면도·측면도 치수와 굽힘 수를 표로 정리
- **도면 치수 읽기 게임** — 도면을 보고 치수·개수·합을 맞히는 12문항
- **제어 과제 12세트** — 테스트동작 표 / 변위단계선도 / 연속동작 / 부가조건 1·2 / 배치도 / 공기압 회로도
- **동작 시뮬레이터** — 세트별 테스트동작을 실린더·램프 애니메이션으로 재생
- **동작 순서 맞추기** — 제어요소 동작 순서를 세우는 게임
- **실격조건 O·X** — 수험자 유의사항의 실격 항목 골라내기
- **실기 점검 20문항** — 조립·제어 전 범위, 100점 환산

## 계급(랭크) 시스템

게임·점검을 풀면 **RP(랭크 포인트)** 가 쌓이고 계급이 올라갑니다.

🪨 아이언 → 🥉 브론즈 → 🥈 실버 → 🥇 골드 → 💠 플래티넘 → 💎 다이아몬드 → 👑 마스터

- 55점이 본전, 100점이면 퍼펙트 보너스 +12 RP
- 3연승부터 연승 보너스(최대 +15 RP)
- 하락은 최대 −22 RP, 아이언·브론즈는 보호
- 홈의 **🏆 계급표**에서 사다리·계산식·최근 기록을 볼 수 있습니다
- `?rc=` 로 열면 제출 결과에 계급과 RP가 함께 기록됩니다

공용 위젯 `links/rank.js` 를 씁니다. 저장은 기기별 localStorage.

## 자료 출처

한국산업인력공단 Q-Net 「반도체설비보전기능사 공개문제」(2023-12-15 등록)
- 시험1 반도체설비 조립작업
- 시험2 반도체설비 제어작업

도면·도해는 원본을 그대로 크롭했고, 설명과 문항은 공개문제 내용을 바탕으로 작성했습니다.

> 공개문제는 "일부 요구사항 등이 변경될 수 있음"으로 안내됩니다. 시험 전 Q-Net에서 최신본을 확인하세요.
